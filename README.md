# Freelancer Invoicing

A web app that helps freelancers create invoices, send them to clients, and get paid. Clients can view and pay an invoice through a public link, and the app tracks each invoice's status (sent, viewed, paid, overdue). It also sends automatic payment reminders.

This is a learning project built to practice a full software development workflow: issues, branches, pull requests, automated testing, and deployment pipelines.
